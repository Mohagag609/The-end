# Musharaka Pro - نظام محاسبي متكامل

نظام محاسبي متكامل لإدارة المشروعات والشركاء والمحاسبة المالية، مبني بـ Django و Tailwind CSS.

## المميزات الرئيسية

### 1. إدارة المشروعات
- إنشاء وإدارة مشروعات متعددة
- تقسيم المشروعات إلى مراحل
- إدارة المخازن لكل مشروع

### 2. إدارة الشركاء والمحافظ
- إضافة شركاء بنسب مختلفة (يجب أن يكون المجموع 100%)
- محافظ إلكترونية لكل شريك
- سندات قبض وصرف
- خصم متسلسل من المحافظ

### 3. المشتريات والموردين
- إدارة الموردين (مشتركون على مستوى النظام)
- فواتير الشراء مع الضرائب
- ربط المشتريات بالمخزون تلقائياً

### 4. إدارة المخزون
- أصناف مع فئات (حديد، أسمنت، إلخ)
- حركات المخزون (وارد/صادر)
- صرف المواد للمراحل = مصروف تلقائي
- حساب متوسط التكلفة المرجح

### 5. المصروفات
- مصروفات يدوية على المشروع/المرحلة
- فئات متعددة للمصروفات
- مصروفات سريعة من لوحة التحكم

### 6. التوزيعات (Allocations)
- حساب Delta (الفرق بين التكلفة والموزع)
- توزيع بالحصة أو مخصص
- خصم من محافظ الشركاء

### 7. التسويات الدورية
- تسويات بين الشركاء حتى تاريخ معين
- حساب ما يجب تحمله vs ما تم دفعه
- توليد مطالبات بين الشركاء
- ترحيل الأرصدة للفترة التالية

### 8. التقارير
- كشف حساب الشركاء
- كشف حساب الموردين
- كشف حساب الحديد (أو أي فئة)
- تصدير CSV
- شاشة مؤشرات KPIs

## التثبيت المحلي

### المتطلبات
- Python 3.11+
- pip
- venv

### خطوات التثبيت

1. استنساخ المشروع:
```bash
git clone <repository-url>
cd musharaka_pro
```

2. إنشاء البيئة الافتراضية:
```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# أو
venv\Scripts\activate  # Windows
```

3. تثبيت المكتبات:
```bash
pip install -r requirements.txt
```

4. إعداد قاعدة البيانات:
```bash
python manage.py migrate
```

5. إنشاء مستخدم إداري:
```bash
python manage.py createsuperuser
```

6. تشغيل الخادم:
```bash
python manage.py runserver
```

7. فتح المتصفح على:
```
http://localhost:8000
```

## النشر على Render

### الخطوات:

1. إنشاء حساب على [Render.com](https://render.com)

2. ربط مستودع GitHub

3. إنشاء Web Service جديد:
   - اختر Python environment
   - Build Command: `./build.sh`
   - Start Command: `gunicorn musharaka_pro.wsgi:application`

4. إضافة متغيرات البيئة:
   - `SECRET_KEY`: توليد تلقائي
   - `DEBUG`: `False`
   - `ALLOWED_HOSTS`: `.onrender.com`
   - `DATABASE_URL`: سيتم إنشاؤه تلقائياً

5. إنشاء قاعدة بيانات PostgreSQL:
   - اختر الخطة المجانية
   - سيتم الربط تلقائياً

6. النشر!

## استخدام النظام

### 1. البداية
- قم بتسجيل الدخول
- أنشئ مشروعاً جديداً من الصفحة الرئيسية
- أدخل كود المشروع واسمه

### 2. إضافة الشركاء
- من لوحة تحكم المشروع، اضغط "إضافة شريك"
- أدخل اسم الشريك ونسبته
- تأكد أن مجموع النسب = 100%

### 3. إيداع في المحافظ
- اضغط "قبض" بجانب اسم الشريك
- أدخل المبلغ والتاريخ
- سيتم توليد رقم السند تلقائياً

### 4. إضافة مراحل
- اضغط "إضافة مرحلة"
- أدخل اسم المرحلة والميزانية

### 5. تسجيل المصروفات
- استخدم "مصروف سريع" من لوحة التحكم
- أو اذهب لصفحة المصروفات للتفاصيل

### 6. توزيع Delta
- عندما تظهر Delta في المرحلة
- اضغط "توزيع Delta"
- اختر التوزيع بالحصة أو مخصص

### 7. التسويات الدورية
- اذهب لصفحة التسويات
- أنشئ تسوية جديدة بتاريخ القطع
- راجع الفروقات والمطالبات
- رحّل التسوية
